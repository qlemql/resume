01주문·광고 모듈의 통신 오류와 노출 조건 개선

Vue 주문 앱 안의 React 광고 모듈이 준비되기 전에 메뉴판을 덮어 터치를 막고, 광고 간 상태 처리 오류로 다음 송출이 누락되는 문제가 있었습니다.

  • iframe 생성과 노출을 분리하고 준비 완료 신호(ACK)를 받은 뒤 표시하도록 수정했습니다. 응답 시간 초과와 늦게 도착하는 ACK를 처리하고, 이전 광고 종료와 다음 응답 대기 상태를 분리해 회귀 테스트를 추가했습니다.
  • Vue 반응형 객체의 postMessage 전송 실패는 공통 송신 함수에서 일반 객체로 변환해 해결했습니다. PM과 선·후결제 광고 노출 조건을 정리하고 결제 중 새로고침과 장바구니 위 광고 노출을 막았습니다.
